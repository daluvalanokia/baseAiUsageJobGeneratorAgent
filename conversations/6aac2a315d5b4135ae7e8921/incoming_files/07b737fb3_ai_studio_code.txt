  Surface Structure (TopX, TopY, TopZ)
         ▲
         │ (StructureVertexId - Common Spatial Axis)
         ▼
  Ground Surface (BottomX, BottomY, BottomZ = SurfaceElevationM)
         │
  Foundation Interface (FoundationDepthM, FoundationBottomElevationM)
         │
  Geotechnical Profile Intervals (Duplicated Structure Vertices projected along Z-axis)
         ├── Fill / Topsoil [Layer 0]
         ├── Sand / Silt / Alluvial Deposit [Layer 1]
         ├── Dense Glacial Till / Clay [Layer 2]
         ├── Weathered Rock Transition [Layer 3]
         └── Competent Bedrock [Layer 4] (BedrockTopElevationM)
         │
  Hydrological Profile (GroundwaterTableElevationM, Pore Pressure)
         │
  Off-Site Corroborating Boreholes (Boreholes & BoreholeIntervals with distance/bearing offset)


Key Notes:
Vertical Digital-Twin via Vertex Duplication: Each StructureVertexId of a structure's polygon perimeter acts as a vertical borehole-axis anchor. Subsurface geometry duplicates this perimeter downwards across discrete stratigraphic interfaces (Ground, Foundation Base, Layer Boundaries, Bedrock, and Groundwater Table).
Explicit Provenance & Inference Distinction: Direct measurements (borehole core logs, geotechnical reports) are distinguished from geostatistical interpolations (Kriging / inverse distance weighting from regional maps).
Change Classification Discipline: Changes between subsurface versions are classified into PHYSICAL_CHANGE (settlement, groundwater fluctuation, void formation) vs. DATA_REFINEMENT (new borehole drilled, revised geological map), preventing spurious alerts.
